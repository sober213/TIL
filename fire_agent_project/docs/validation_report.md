## 아직 확인하지 못한 항목

- 발급된 OpenAI 키를 사용한 실제 LLM 호출 및 모델 응답 검증
- 발급된 API 키를 사용한 3개 외부 API 실호출 및 응답 필드 검증
- API 인증키 누락/외부 API 장애를 실제 호출로 재현한 화면 캡처
- 실제 브라우저(Chrome/Edge)에서 반응형 UI 및 사용자 동선 확인
- 재계획 발생/상한 도달 시나리오를 외부 API 응답으로 재현
- API별 호출 한도와 이용약관 원문 확인

## 대표 시나리오 준비

1. 강원도 산불 위험 후보 5곳 조회
2. 강원도 산불 위험 후보 + 과거 산불 이력 + 기상 관측 조회
3. 지역별 위험예보 조회 결과가 비어 전국 조회로 fallback되는 상황
4. API 키를 제거해 Tool 실패를 확인하는 상황
5. 인사/사용법 질문으로 Tool이 호출되지 않는 상황

실제 API 결과와 화면 캡처는 실키 환경에서 수행한 뒤 이 문서에 추가해야 한다. 현재 보고서의 자동 테스트는 외부 API를 모의한 로컬 검증이며 실제 API 성공을 의미하지 않는다.
