# 요구사항 정의 및 구현 점검표

상태는 현재 소스코드 기준이며, 외부 API 키를 이용한 실제 호출 검증 여부와 구분한다.

| 번호 | 요구사항 | 현재 구현 | 상태/남은 검증 |
|---|---|---|---|
| F3001 | Tool 명세·등록 | 공통 Tool dataclass, JSON Schema, catalog, 성공/실패 공통 응답 | 구현. 상세 Tool은 사용자가 상세 조회를 요청할 때 후보 코드로 호출 |
| F3002 | 후보 조회 | 산불위험예보 API를 후보 조회 Tool로 래핑 | 구현. API 실제 응답 필드/페이지 범위 검증 필요 |
| F3003 | 상세정보 조회 | 시군구 코드 기반 상세 조회 Tool 제공 | 부분 구현. API가 반환하는 상세 필드 범위와 코드 연계 실호출 확인 필요 |
| F3004 | 보조 정보 검색 | 기상청 ASOS 일자료 Tool | 구현. 지역별 관측소 매핑 확장 검증 필요 |
| F3005 | 사용자 요청 분석 | OpenAI LLM으로 지역, 개수, 날짜 범위, 조회 종류 추출. 미설정/실패 시 규칙 기반 대체 | 구현 보완. 실제 OpenAI 키를 이용한 호출 검증 필요 |
| F3006 | 작업 계획 수립 | 의도에 따라 Tool과 순서 구성 | 부분 구현. 규칙 기반이며 LLM Planner는 없음 |
| F3007 | Tool 호출·결과 통합 | 순차 실행, 실패 격리, 지역 필터, 실행 요약 | 부분 구현. 외부 API 응답 스키마 변동 및 페이지네이션 검증 필요 |
| F3008 | 제약 적합성 판단 | 조회된 지수의 숫자 정렬, 조회 근거와 자료 부재 표시 | 부분 구현. 공식 위험등급 기준을 확인하기 전 임의 등급/확률 산출 안 함 |
| F3009 | 재계획 | 지역별 조회 실패 시 전국 조회로 1회 보완, 상한 관리 | 부분 구현. 일반 후보 대안 탐색은 없음 |
| F3010 | 대화 맥락 유지 | 세션별 최근 대화 저장, 후속 문맥 표현에 직전 요청 반영 | 부분 구현. 대화 조건의 정교한 병합/수정은 제한적 |
| F3011 | 최종 응답 | 후보, 지수 원자료, 조회 근거, 실패 및 안전 안내 제공 | 부분 구현. 데이터 가용성에 따라 일부 항목은 미표시 |
| F3012 | 실행 이벤트 발행 | 단계 시작/종료, Tool 호출/응답, LLM 의도 분석 판단/사유, 재계획 이벤트 | 구현 보완. 실제 LLM 판단 이벤트는 키 설정 후 검증 필요 |
| F3013 | 실행 로그 저장 | 이벤트 구독 후 SQLite에 원본 순서대로 저장, LLM 미사용 | 구현 |
| F3014 | 로그 조회·삭제 | 세션 목록/상세/삭제 API, 수정 API 없음 | 구현 |
| F3015 | 계획 저장·조회 | SQLite 저장/목록/상세, 날짜·시간 중복 경고 | 구현 |
| F3016 | 계획 수정·삭제 | PUT/DELETE 및 목록 반영 | 구현 |
| F3017 | FastAPI | 대화, Tool 목록, 계획, 로그 API | 구현 |
| F3018 | 프론트엔드 | 대화/계획 관리/로그 화면, 동일 출처 API 연동 | 기본 구현. 브라우저별 UI 확인 필요 |
| F3019 | 실행 상태 표시 | 처리 중 표시, 이벤트 순서·Tool·재계획 표시, 오류 안내 | 기본 구현. 화면 캡처/실제 API 실패 시나리오 검증 필요 |

## 비기능 요구사항

- NF3001: `.env` 기반 키 관리, `.gitignore`에서 `.env` 제외.
- NF3002: API 키와 원시 오류 상세는 프론트엔드에 반환하지 않음.
- NF3003: Tool 실패는 공통 실패 응답으로 격리하고 후속 단계 진행.
- NF3004: 재계획 횟수 상한을 상태에 두고 1회 fallback으로 제한.
- NF3005: 로컬 구조 테스트는 빠르게 통과. 외부 API 응답시간은 실키 환경에서 측정 필요.
- NF3006: Agent, Tool, API, 저장소, 프론트엔드 파일 분리.
- NF3007: API 출처는 Tool 정의서에 기록. 호출 한도·이용약관은 발급 포털에서 프로젝트 제출 전 확인 필요.

심화 F3020~F3023은 필수 기능 이후 수행하도록 범위에서 제외했다.
