참함수와 측정오차 - 측정오차는 줄일 수 x 참함수에 다가가는 것 
#### 2-1 MSE(Mean Squared Error?)(숫자형 자료)
오차 제곱 평균, 오차를 제곱해 분별이 쉬워지고 구체적 수치 
RMSE: 제곱한 게 너무 커서? 제곱근 적용?
#### 2-2 R**2(결정계수)(숫자형 자료)
조화평균, 오차를 서로 비교하기 쉽게끔 만들어줌 
#### 2-3 ??(범주형 자료)
비균형 자료의 경우 정답률은 99%에 이를 수 있지만(암환자 찾기) 
실제 중요한 정확성을 챙겨야 함
#### 2-4 혼동행렬(범주형 자료)
정확성 TP(맞췄고 양성), TN(맞췄고 음성), FP(틀렸고 양성이라 함), FN(틀렸고 음성이라 함)
#### 3 학습
학습할 때 제대로 학습해야 함  
#### 4 테스트/ 검증Validation
훈련 오류(문제집 정답)/ 테스트 오류(실제 시험 정답)
오버피팅(답지만 달달 외운 놈), 언더피팅(그냥 학습을 못한 놈)
훈련 오류보다 테스트 오류를 잡는 게 본질적인 목표 
#### 4-1 검증 데이터 셋(Hold)?
데이터를 쪼개 학습용, 테스트용으로 따로 던져줌/ 쪼개지는 만큼 학습능력이 떨어져
평가오류 발생 가능
#### 4-2 K-Folding set
10개 쪼개서 하나씩 시험지로 쓰는 느낌 - 하나로 하면 LOOV? 품이 많이 듦
쪼갠 테스트 데이터가 겹치지 않도록 주의 
#### 5 비지도학습
레이블이 없는 데이터를 기준에 따라 묶기, 출력은 정답이 아닌 패턴, 집합
#### 5-1 K-클러스터링
1 ~ K개의 중심점? 할당-> 집단 형성/ 각각의 집단은 상이
군집화, 가까이 만들고 점점 중심점이 최적화되는 식 - 기준값 중요
#### 5-2 계층적 군집화(Hierachical Clustering?)
나무 형태로 잎-가지-나무로 큰 데이터에는 사용이 어려움
덴드로그램으로 표현- 병합, 상향식 분류가 이루어져 체계적이나 큰 데이터 적용 x
