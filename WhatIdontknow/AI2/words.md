### 잘 모르는 용어

#### MLP
- MLP(Multi-Layer Perceptron, 다층 퍼셉트론):
>고전적 머신러닝의 한계(사람이 힌트를 준다) 극복, 초창기 인공신경망(Artificial Neural Network), 이미지에 약함

- 라이브러리
>재사용 가능한 코드 묶음(함수, 클래스들). 반복 구현을 줄여주고 검증된 구현 활용

- 트랜스포머
>self-attention 기반의 시퀀스 모델 구조로, 병렬 학습과 긴 문맥 처리에 강함. 현대 NLP, 생성모델의 핵심

- 퍼셉트론
>입력(inputs, x), 가중치(weights, w), 가중합(Weighted Sum), 활성화 함수(Activation Function)- 전달할까 말까 <-이걸로 구성된 기본 블록 

- XOR
>두 입력이 서로 다를 때만 1을 출력하는 문제/ 직선 하나로는 해결이 어렵다! 퍼셉트론을 다층 구조로 쌓으면 되지만 각 층의 가중치를 어떻게 학습시키지? (1969)

- 입력층, 은닉층, 출력층
>데이터가 들어오고 은닉층에서 특징을 추출 학습, 출력층으로 최종 예측 결과 내보내기 은닉층 == 종이를 접는 손(직선으로 나눌 수 있게 공간을 바꿔놓음)

- Flatten
>다차원 배열(텐서)을 1차원으로 펼치는 연산

- RAG(Retrieval-Augmented Generation)
>외부 지식을 검색해 생성 모델 입력에 결합해 답을 만드는 방법

- 비선형성
>활성화함수 등 선형 변환 뒤에 넣는 비선형 연산. 신경망이 복잡한 함수를 근사하도록 함.

- 시그모이드 함수
>S자 곡선 (기울기 최대: 0.25) 층을 10번 거치면 0.25 * 10 사실상 0에 수렴하게 됨
>퍼셉트론이 가중합을 구해서 "이렇게 고쳐라!" 해야 하는데 앞층까지 못가고 사라짐

- 순전파(Foward Propagation)
>일단 요리해보는 것. 입력 데이터가 입력층에서 출력층까지, 최종 예측 값을 계산. 
>가중치가 무작위라 맛없는 예측 결과

- 손실 함수(모델의 오답노트)
>망한 요리와 실제 정답 비교, 손실/오차를 하나의 숫자로 계산(회귀: 평균 제곱 오차-얼마나 멀리 빗나갔지?, 분류: 교차 엔트로피- 정답을 얼마나 확신했지?) 손실값

- 역전파(Back Propagation)
>원인 분석. 누구 책임인지 거꾸로 추적. 최종 손실에 얼마나 영향을 미쳤는지 책임계산, 앞쪽 층으로 계속 전달, 자신의 책임량에 비례하여 "손실을 줄이는 방향"으로 업데이트

- 옵티마이저(똑똑한 가중치 업데이트)
>손실 함수 값이 최소가 되는 최적의 가중치를 효율적으로 찾아가는 알고리즘, Adam(Adaptive Moment Estimation)-표준 옵티마이저 "경사하강법(Gradient Descent, GD)"

- ReLU(Rectified Linear Unit)
>지금 활용하는 함수. 입력이 0보다 크면 그 값 그대로, 음수면 0으로 통일하는 단순한 규칙. 기울기가 1, 0이라 아무리 곱해도 1이라 신호가 사라지지 않음

- 벡터
>크기와 방향을 가진 수치 배열, 데이터-특징-임베딩을 수치적으로 표현하는 기본 단위. 

- PyTorch
>파이썬을 위한 대표적인 딥러닝 프레임워크

- AutoGrad
>Pytorch의 핵심 기능

- 드롭아웃(Dropout)
>훈련 시, 은닉층의 뉴런을 일정 확률로 랜덤하게 OFF시킴 추론 시엔 전부 ON 이를 통해 특정 뉴런에 지나치게 의존 방지, 매번 다른 네트워크 학습과 같은 앙상블 효과 냄

- 학습 루프(Training Loop)
>순전파-> 손실 함수-> 역전파-> 업데이트 4단계 무한반복

- 조기 종료(Early Stopping)
>모델의 검증 성능이 더 이상 개선되지 않으면 학습을 조기에 멈추는 기법. 과적합을 방지하고 불필요한 연산을 줄여 안정적인 모델을 얻기 위해 필수

- 학습률(LearningRate)
>가중치 업데이트 시 한 스텝으로 이동하는 크기(스텝사이즈) 너무 크면 발산·오버슈팅, 너무 작으면 느린 수렴이나 지역최소에 갇혀 튜닝의 핵심

- 오버슈팅
>학습률 등이 커서 최적점을 넘겨버려 손실이 발산하거나 진동하는 현상 

- AdamW
>Adam 최적화에 weight decay(가중치 감쇠)를 decoupled 방식으로 도입한 옵티마이저

- 관성(Momentum)
>이전 기울기의 일부를 현재 업데이트에 더해 방향성을 유지하고 노이즈를 줄이는 기법, 수렴을 가속화하고 비슷한 방향의 업데이트를 강화

- 가중치(Weights)
>신경망이 학습으로 조정하는 파라미터들로, 입력을 출력으로 변환하는 계수들

- 딥러닝
>여러 층의 인공신경망을 이용해 데이터로부터 계층적 표현을 학습하는 머신러닝 분야, 다양한 문제에서 최고 성능을 내므로 전반적 원리 숙지 중요

- pandas DataFrame
>테이블 형태로 데이터를 저장하고 요약 통계, 선택-조작 기능을 제공하는 라이브러리

- 과소적합(Underfitting)
>모델이 너무 단순해서 학습 데이터조차 잘 맞추지 못하는 상태, 둘 다 성능낮음- 해결하려면 모델 복잡도 증가, 특성 추가, 학습 시간 증가

- StandardScaler
>피처별 평균을 0, 분산을 1로 표준화하여 머신러닝 모델 학습을 안정화하는 전처리 기법

- RMSE, MAE, R**2
>오차를 제곱해 평균 낸 뒤 제곱근, 오차 절댓값의 평균, 모델이 설명한 분산의 비율 지표

- 중앙값
>평균치가 아닌 최대 최소 정확히 중간에 위치한 값? 

- NumPy
>배열 연산: 배열 기반 고속 수치 연산과 통계 함수(평균-표준편차-히스토그램 등)을 지원

- Validation
>검증- 검증 데이터는 하이퍼파리미터를 조정하고 모델을 선택하는 데 사용

- 특성(feature)
>데이터를 입력할 때 구분하는 묶음?

- nunique()
>중복을 제외한 고유값 개

- .std(ddof=1)
>표본표준편차(n-1로 나눔)pandas 관용구 numpy는 기본이 ddof = 0이라 다른 값 나옴

- 피어슨 상관계수(Pearson's r)
>가장 접근과 해석이 쉬운 상관관계, 두 변수 사이의 선형관계를 -1에서 1사이로 표

- matrix
>2차원 배열?

- PCA
>차원 축소

- histplot()
>변수별 분포를 히스토그램과 KDE(커널 밀도 추정)로 동시에 시각화

- scatterplot()
>산점도(선 주변에 막 점 흩어져있는 그래프)

- pairplot()
>여러 피처 쌍에 대한 산점도,분포도를 한 번에 그려 상관관계와 분포 형태를 종합 탐

- LogisticRegression
>선형 방정식을 기반으로 확률적 분류를 수행하는 지도 학습 알고리즘

- 레이블
>정답(데이터상)

- seaborn
>통계적 데이터 시각화에 특화된 파이썬 라이브러리로, 복잡한 그래프를 간단한 API로 그리게 해 줍니다. 실무에서 탐색적 데이터분석(EDA)을 빠르고 보기 좋게 하려면 필수입니다.

- IQR 기반 이상치 처리 
>사분위수 범위(IQR)를 이용해 이상치를 판정(보통 Q1 - 1.5IQR, Q3 + 1.5IQR)하고 제거·대체하는 방법입니다. 이상치가 모델 성능에 미치는 영향을 줄이기 위해 알아둬야 합니다.

- SimpleImputer
>sklearn의 결측치 대체 유틸리티로 평균·중앙값·최빈값 등으로 결측을 채웁니다. 결측 처리 파이프라인화에 편리하므로 재현 가능한 전처리에 필요합니다.

- 최빈값(mode):
>데이터에서 가장 자주 등장하는 값입니다. 범주형 결측치 대체나 대표값 선택 시 자주 사용됩니다.

- IQR: 
>Q3 - Q1으로 정의되는 중앙 주변의 산포 척도입니다. 이상치 판정과 분포 이해에 유용합니다.

- 분산(variance): 
>데이터가 평균으로부터 얼마나 흩어져 있는지의 제곱 평균입니다. 특징 스케일링·모델의 불안정성 이해에 필요합니다.

- 알고리즘: 
>문제 해결을 위한 절차나 방법의 집합입니다. 적절한 알고리즘 선택이 성능과 효율을 결정하므로 익혀야 합니다.

- 함수(function): 
>입력을 받아 출력을 생성하는 코드 블록입니다. 재사용성과 모듈화를 위해 기본 개념을 잘 알아야 합니다.

- 브로드캐스팅(broadcasting):
>서로 다른 차원의 배열 간 연산에서 작은 배열을 자동 확장해 연산하게 하는 규칙입니다. numpy 연산을 간결하고 빠르게 쓰려면 필수 개념입니다.

- 벡터화(vectorization): 
>루프 대신 배열 연산으로 처리해 성능을 높이는 기법입니다. 데이터 처리·수치 연산 속도 향상에 중요합니다.

- 데이터셋(dataset): 
>학습·평가용 데이터의 모음입니다. 데이터 품질 관리와 분할 전략 수립에 핵심입니다.

- repository: 
>코드·데이터를 저장·관리하는 장소(예: Git repo). 협업·버전관리·재현성 확보를 위해 필수입니다.

- 선형 회귀(linear regression):
>입력의 선형 조합으로 연속형 타깃을 예측하는 통계·머신러닝 모델입니다. 해석성 높고 기초 모델로 널리 쓰입니다.

- fetch: 
>원격/로컬에서 데이터나 리소스를 가져오는 행위나 함수입니다. 데이터 입수 과정을 자동화·재현할 때 유용합니다.

- .drop:
>pandas에서 행/열을 삭제하는 메서드입니다. 불필요한 컬럼·결측 큰 행 제거 등에 자주 씁니다.

- .frame:
>보통 DataFrame을 가리키는 약어 또는 클래스명(pandas.DataFrame). 표형 데이터 처리를 위해 기본 구조를 이해해야 합니다.

- matplotlib.pyplot:
>matplotlib의 절차적 인터페이스로 기본 시각화 기능을 제공합니다. 세부 커스터마이징 시 꼭 익혀야 합니다.

- axis=1: 
>pandas·numpy에서 연산을 열 방향(열 단위)으로 적용하겠다는 의미입니다(axis=0 은 행 방향). 올바른 축 지정이 데이터 변환 결과를 결정합니다.

- astype(int): 
>pandas에서 시리즈 또는 배열의 자료형을 정수형으로 변환하는 메서드입니다. 자료형 통일과 연산 안정성을 위해 필요합니다.

- 분포(distribution): 
>데이터 값들이 어떻게 퍼져 있는지를 나타내는 통계적 개념입니다. 모델 선택·변환(예: 로그) 판단에 도움됩니다.

- 타겟 변수(target): 
>예측하려는 종속 변수(레이블)입니다. 문제 정의와 평가 지표 선정의 출발점입니다.

- 단위 k:
>보통 수치의 단위를 천(k)을 뜻하는 약어로 표기(예: 1k=1000). 가시화나 해석 시 단위 통일이 중요합니다.

- assert: 
>조건이 참인지 검사하고 거짓이면 예외를 발생시키는 디버깅용 문장입니다. 코드의 전제(전조건)를 검증해 버그를 빨리 찾을 때 유용합니다.

- Series: 
>pandas의 1차원 라벨된 배열 자료구조입니다. 단일 속성 데이터 조작에 기본 단위입니다.

- ratio:
>두 값의 비율입니다(예: A/B). 상대적 비교 및 정규화에 자주 사용됩니다.

- .quantile:
>pandas에서 분위수(예: 0.25, 0.5, 0.75)를 계산하는 메서드입니다. 분포 요약과 IQR 계산에 필요합니다.

- 수치형 변수(numeric feature):
>연속적이거나 순서형으로 수치 연산이 가능한 변수입니다. 전처리·스케일링·모델링 방식이 달라지므로 구분해야 합니다.

- corr: 
>pandas의 상관계수 계산 메서드(df.corr())로 변수간 선형 상관을 수치화합니다. 특징 선택과 다중공선성 진단에 필요합니다.

- 상관행렬(correlation matrix):
>변수들 간의 상관계수를 행렬 형태로 정리한 것. 변수 관계를 한눈에 파악하는 데 유용합니다.

- 특성 쌍(feature pair):
>두 개의 특성(변수)으로 구성된 조합입니다. 상관·상호작용 분석 시 자주 고려합니다.

- Arguments:
>함수에 전달되는 매개변수(인자)들입니다. API 사용과 함수 설계에서 핵심 개념입니다.

- abs():
>절댓값을 반환하는 함수(파이썬 내장 또는 numpy.abs). 차이·오차의 크기 비교 등에 기본적으로 씁니다.

- LSTAT: 
>보스턴 주택 데이터셋에서 하위계층 인구 비율을 나타내는 변수명 예시입니다(문맥에 따라 변수명). 도메인 특성 이해가 해석에 중요합니다.

- annot: 
>seaborn의 heatmap 등에서 셀에 값을 표기할지 여부를 지정하는 인자입니다. 시각적으로 수치 확인이 필요할 때 
켭니다.

- fig, ax:
>matplotlib에서 Figure와 Axes 객체를 받는 변수 관습입니다. 복잡한 플롯 제어(서브플롯·레이아웃)에 필수입니다.

- np.: 
>numpy 모듈 접두사로 수치 연산 함수를 호출할 때 사용합니다. 배열 연산·통계 함수를 자주 쓰므로 익숙해야 합니다.

- 다중공선성(multicollinearity):
>독립 변수들 간 높은 상관으로 회귀계수 불안정성이 생기는 현상입니다. 모델 해석성과 일반화에 악영향을 미치므로 진단·대처 필요합니다.

- 도메인(domain): 
>문제·데이터가 속한 실제 분야(예: 의료, 금융). 도메인 지식은 변수 선택·전처리·해석을 크게 개선합니다.

- Ridge 회귀:
>L2 정규화를 추가한 선형 회귀로 과적합과 다중공선성 완화에 도움됩니다. 규제 강도를 조정하면 일반화 성능을 개선할 수 있습니다.

- coef_: 
>sklearn 모델에서 학습된 선형 계수를 담는 속성입니다. 특성 중요도·영향력 해석에 사용됩니다.

- 로그 변환(log transform): 
>데이터의 스케일을 줄이고 비대칭 분포를 정규화하기 위해 로그를 취하는 변환입니다. 분포 안정화·선형성 개선에 자주 씁니다.

- subplots(): 
>matplotlib에서 여러 서브플롯(axes)을 만드는 함수입니다. 비교 시각화나 레이아웃 구성에 유용합니다.

- boxplot(): 
>분포의 사분위수와 이상치를 시각화하는 상자그림 함수입니다. 변수의 중앙·산포·이상치 탐지에 직관적입니다.

- 데이터 분할 재현성: 
>train/test 분할 시 동일한 결과를 얻도록 난수 시드(random_state)를 고정하는 practice입니다. 실험 재현과 비교를 위해 중요합니다.

- stratify: 
>sklearn의 train_test_split 등에서 클래스 비율을 유지하며 분할하도록 하는 인자입니다. 클래스 불균형 문제에서 타깃 분포를 보존하려면 필요합니다.

- 연속형 변수(continuous variable): 
>실수 범위로 연속적인 값을 갖는 변수입니다. 분포·변환·모델링 방법이 범주형과 다릅니다.

- qcut: 
>pandas의 분위수 기준으로 데이터를 구간화하는 함수입니다(quantile-based binning). 균등한 샘플 수의 구간을 만들 때 편합니다.

- duplicates: 
>데이터에서 중복된 행 또는 값들입니다. 중복은 통계 왜곡이나 데이터 누수의 원인이 되므로 처리해야 합니다.

- bins: 
>연속형 데이터를 구간화할 때 나누는 구간 경계들입니다. 히스토그램·카테고리화에서 사용됩니다.

- bounds: 
>값의 하한·상한을 의미합니다. 값 검증·이상치 처리에서 기준으로 씁니다.

- mask: 
>배열·데이터프레임에서 특정 원소를 선택 또는 제외하는 불리언 배열입니다. 조건 기반 필터링에 유용합니다.

- {:.1f}: 
>파이썬 포맷 문자열로 소수 첫째 자리까지 포맷하는 표현입니다. 숫자 표시 형식을 통일할 때 씁니다.

- 데이터 누수(data leakage): 
>학습 시 테스트에 영향을 주는 정보가 훈련에 포함되는 현상으로, 성능이 부풀려집니다. 모델의 일반화 신뢰도를 위해 반드시 방지해야 합니다.

- sklearn: 
>scikit-learn, 파이썬의 대표 ML 라이브러리로 다양한 알고리즘·전처리·평가 도구를 제공. 표준화된 API로 실무·연구에서 광범히 사용됩니다.

- SVD 기반 최소제곱: 
>선형 시스템을 SVD로 풀어 최소제곱 해를 안정적으로 구하는 방법입니다. 수치적으로 안정적인 해법이 필요할 때 유용합니다.

- intercept_: 
>선형 모델의 절편(편향) 파라미터입니다. 예측의 기준선(intercept) 이해에 필요합니다.

- TAX 단위: 
>문맥에 따라 세금 관련 변수(TAX)의 단위를 의미; 해석 시 단위 확인은 필수입니다. (단위는 모델 해석·스케일링에 영향)

- NOX 단위: 
>공기질 변수(NOx 등)의 단위를 의미; 단위·스케일을 몰라서 해석을 오해하면 안 됩니다.

- 선형 회귀 계수: 
>각 특성이 타깃에 미치는 선형 영향도(가중치)입니다. 계수 크기·부호로 특성 중요도를 해석할 수 있습니다.

- Permutation Importance: 
>모델 성능 기반으로 특성 중요도를 측정하는 방법으로, 특성 값을 섞어 성능 저하를 관찰합니다. 모델-불변적 중요도 평가로 신뢰성을 보완합니다.

- SHAP: 
>SHapley Additive exPlanations로, 개별 예측에 대한 특성 기여도를 공정하게 분배하는 해석 기법입니다. 로컬·글로벌 해석에 강력한 도구입니다.

- _val: 
>보통 내부(임시) 변수명 접미사로 사용되는 관습적 이름(예: metric_val). 컨벤션이라 용도는 코드 맥락에 따라 달라집니다.

- 이분산성(heteroscedasticity): 
>잔차의 분산이 설명 변수 수준에 따라 달라지는 현상입니다. 회귀 가정 위배이므로 진단·변환(가중회귀 등)이 필요합니다.

- 잔차 그래프(residual plot): 
>예측오차(잔차)를 시각화한 그래프으로 패턴·이분산성·비선형성을 탐지합니다. 모델 적합성 진단에 기본 도구입니다.

- 혼동 행렬(confusion matrix): 
>분류 결과를 행렬로 정리해 TP/TN/FP/FN을 보여줍니다. 분류 성능의 상세 분석에 필수입니다.

- Classification Report, ROC-AUC: 
>분류 성능(정밀도·재현율·F1 등) 보고서와 수신자 조작 특성 곡선 아래 면적(ROC-AUC)으로, 모델 비교·임계값 설정에 중요합니다.

- 군집화(KMeans)(Clustering): 
>비지도학습으로 데이터를 유사도 기준 군집으로 묶는 알고리즘(예: KMeans). 데이터 구조 탐색·세그멘테이션에 활용됩니다.

- 인사이트(insight): 
>데이터·모델로부터 얻는 의미 있는 발견입니다. 비즈니스 결정·가설 검증에 직결되므로 도출 능력이 중요합니다.

- 파이프라인(pipeline): 
>전처리·모델을 순차적으로 연결해 재현 가능한 워크플로우를 만드는 구조(sklearn.Pipeline 등). 실험 재현성과 
코드 간결성을 위해 필수입니다.

- 프레임워크(framework): 
>개발·연구에 필요한 구조와 도구를 묶어 제공하는 환경(예: TensorFlow, PyTorch). 표준화된 방식으로 생산성을 높입니다.
