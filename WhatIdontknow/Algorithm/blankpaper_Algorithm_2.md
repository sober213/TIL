### 트리(Tree) 1

#### 1 트리
1 : N 대응관계를 가지는 비선형 자료구조 
부모, 자식 노드를 둠 부모가 없으면 루트(root), 자식이 없으면 리프(leaf)
한 노드를 기점으로 그에 딸린 서브트리, 노드와 간선으로 표현?
#### 2 이진 트리
한 노드가 최대 두 자손만 가질 수 있는 트리 구조 
포화 완전 트리/ 편향 이진 트리
배열 형태로 만들 수 있음
#### 3 순회
트리는 전후관계를 알 수 없음(비선형이라) 앞뒤로 움직이는 개념이 아닌 노드를 모두
들른다는 개념, 탐색 시 트리의 모든 노드를 돌아보는 걸 순회라 함
#### 3.1 전위 순회
V = 부모노드? 순서는 VLR 부모노드 -> 좌측 자손노드 -> 우측 자손노드 순으로 순회
현재 노드 기준? 순서 1(서브트리 덩어리를 하나의 노드로 쳐 나중에?)
#### 3.2 중위 순회
순서는 LVR 좌측 자손노드 -> 부모노드 -> 우측 자손노드 순
#### 3.3 후위 순회 
순서는 LRV 좌측 자손노드 -> 우측 자손노드 -> 부모노드 순
#### 4 이진 탐색 트리
좌측 노드 키 < 루트 노드 키 < 우측 노드 키의 완전 트리 형태 구조
